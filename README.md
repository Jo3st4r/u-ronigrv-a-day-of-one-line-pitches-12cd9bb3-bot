One sentence persuading a friend who has never coded to let an AI
agent build their first app idea, built for the
[make.fun bounty](https://make.fun/bounty/u-ronigrv-a-day-of-one-line-pitches-12cd9bb3).

## The line

> Tell an AI agent your app idea in one sentence, watch it build the
> whole thing, and only pay the builder whose version you love — no
> code, no risk, just the idea you have carried for years finally
> working.

## Run it

```sh
python3 main.py   # writes /output/entry.txt
```
